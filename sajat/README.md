# Saját fájlok

Ide jönnek a te kódjaid és a pmOS-ről átvett javítások.
Részletek és kitöltendő lista: [docs/pmos-javitasok.md](../docs/pmos-javitasok.md).

| Mappa | Tartalom |
|---|---|
| `rootfs/` | fájlok, amik az új rendszerbe kerülnek, **ugyanazzal az útvonallal** (pl. `rootfs/usr/local/bin/sajat.sh`) – a build bemásolja |
| `pmos/` | a `scripts/pmos-gyujto.sh` eredménye (`pmos-gyujtes-*.tar.gz`) |
| `kod/` | saját programok, scriptek forrása |
| `firmware/` | firmware-fájlok (honnan valók: a dokumentum 6. pontja) |
